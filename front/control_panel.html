Aviso importante:
  1. Haz clic en el enlace de arriba; se abrirá la página de Google OAuth en una ventana nueva
  2. Inicia sesión con tu cuenta de Google y concede la autorización
  3. Tras autorizar, se redirigirá a localhost:11451 con una página de éxito
  4. Cierra la ventana de OAuth y vuelve a esta página

🚀 ¿No puedes volver al origen? Prueba el atajo ▼
📚 Cuándo usarlo:
  • Servidores en la nube, VPS y otros entornos no locales
  • El cortafuegos bloquea el acceso al puerto 11451
  • La red no permite volver correctamente a localhost
  • Ejecución dentro de un contenedor Docker con problemas de mapeo de puertos
🔍 ¿Qué es la URL de callback?
Es la URL completa que muestra la barra de direcciones del navegador tras autorizar en Google OAuth; suele tener este aspecto:
http://localhost:11451/?state=abc123...&code=4/0AVMBsJ...&scope=email%20profile...
📋 Pasos a seguir:
  1. Haz clic en el enlace de arriba y completa la autorización de Google
  2. Tras autorizar, copia la URL completa de la barra de direcciones
  3. Pégala en el campo de abajo y pulsa en obtener credencial

Información del proyecto

                
Detalles sobre el proyecto GCLI2API y cómo apoyarlo


                
                

                    
📋 Sobre el proyecto

                    

                        GCLI2API es un proxy que convierte la API de Google Gemini al formato de las API de OpenAI y GEMINI, con gestión multicuenta, rotación automática, registros en tiempo real y más.
                    

                    

                        
🔗 Repositorio: GitHub - su-kaka/gcli2api

                        
⚠️ Aviso de uso: Prohibido el uso comercial y la reventa: solo con fines de aprendizaje

                    

                


                
                

                    
✨ Funciones principales

                    

                        

                            
🔄 Gestión multicuenta: sube y administra varias cuentas de Google por lotes

                            
⚡ Rotación automática: rota las cuentas de forma inteligente para no agotar la cuota de una sola

                            
📊 Monitorización en vivo: estadísticas de uso, seguimiento de errores y registros en tiempo real

                        

                        

                            
🛡️ Seguro y fiable: autenticación OAuth2 y bloqueo automático de cuentas anómalas

                            
🎛️ Configuración flexible: recarga en caliente y ajustes de proxy

                            
📱 Interfaz cuidada: diseño adaptable y optimizado para móvil
