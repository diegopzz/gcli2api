Importante:
  1. Pulsa el enlace de arriba; se abrirá la página de Google OAuth en una ventana nueva
  2. Inicia sesión con tu cuenta de Google y autoriza el acceso
  3. Tras autorizar, se redirigirá a localhost:11451 con una página de éxito

  • Servidores en la nube, VPS y otros entornos no locales
  • El cortafuegos bloquea el puerto 11451
  • La red no permite volver a localhost
  • Ejecución en Docker con problemas de mapeo de puertos
🔍 ¿Qué es la URL de callback?
Es la URL completa que aparece en la barra del navegador tras autorizar en Google OAuth; suele tener este aspecto:
http://localhost:11451/?state=abc123...&code=4/0AVMBsJ...&scope=email%20profile...
📋 Pasos a seguir:
  1. Pulsa el enlace de arriba y completa la autorización de Google
  2. Tras autorizar, copia la URL completa de la barra del navegador
  3. Pégala en el campo de abajo y pulsa en obtener credencial

Información del proyecto

                
Detalles sobre el proyecto GCLI2API


                
                

                    
📋 Descripción

                    

                        GCLI2API es un proxy que convierte la API de Google Gemini a los formatos de OpenAI y GEMINI, con gestión multicuenta, rotación automática y monitorización de logs en tiempo real.
                    

                    

                        
🔗 Repositorio: GitHub - su-kaka/gcli2api

                        
⚠️ Aviso de uso: Prohibido el uso comercial y la reventa: solo con fines educativos

                    

                


                
                

                    
✨ Funciones principales

                    

                        
🔄 Multicuenta: subida y gestión masiva de varias cuentas de Google

                        
⚡ Rotación automática: rota las cuentas para evitar los límites de una sola

                        
📊 Monitorización: estadísticas de uso, control de errores y logs en tiempo real

                        
🛡️ Seguridad: autenticación OAuth2 y bloqueo automático de cuentas con fallos

                        
🎛️ Flexibilidad: ajustes en caliente y configuración de proxy

                        
📱 Interfaz cuidada: diseño responsive y adaptado a móvil
